**Student Name:** Nursultan Karagulov  
**Course:** Web Application Development  
**Semester:** Fall 2025  
**Live Website:** https://popcorn-browse.vercel.app/  


## 1. Project Description

PopcornBrowse is a responsive movie discovery web application that allows users to browse popular, top-rated, now-playing, and upcoming movies. Users can search movies by title, view full movie details including trailers and image galleries, and save their favorite movies to a personal watchlist using Google authentication.

### What the App Does
- Shows trending and popular movies
- Allows searching by movie title
- Displays full movie information with trailer and gallery
- Allows users to save movies to their Watchlist
- Supports light and dark mode
- Works on desktop, tablet, and mobile devices

### Why I Built This Project
I built this project to gain real-world experience with modern web development technologies such as APIs, authentication systems, databases, and React. I also enjoy movies and wanted to create a useful and interactive platform for movie discovery.


## 2. Tech Stack Used

- **HTML5** – Page structure and layout  
- **CSS3** – Styling, animations, responsive design, light/dark theme  
- **JavaScript** – Application logic and interactivity  
- **React.js** – Component-based UI and state management  
- **Firebase Authentication** – Google Sign-In system  
- **Firebase Firestore** – Cloud database for Watchlist  
- **TMDB API** – Provides movie data, trailers, images, and ratings  
- **Vite** – Front-end development and build tool  
- **Vercel** – Hosting and deployment  
- **GitHub** – Version control and source code repository  


## 3. Features

- Browse **Popular, Now Playing, Top Rated, and Upcoming movies**
- Search movies by title
- Filter movies by genre
- Movie details page with:
  - Trailer
  - Rating
  - Overview
  - Release date
  - Image gallery
  - Recommendations
- Google Sign-In authentication
- Personal Watchlist stored in Firestore database
- Light and Dark mode toggle
- Fully responsive design
- Live deployment on Vercel


## 4. How to Run the Project

### Option 1: Run Locally

1. Clone the repository:
git clone https://github.com/kanuaz/popcorn-browse.git

2. Install dependencies:
npm install

3. Run the development server:
npm run dev

4. Open in browser:
http://localhost:5173

### Option 2: Run Online (Deployed Version)

Live Website:
https://popcorn-browse.vercel.app/

No setup is required for the deployed version.
